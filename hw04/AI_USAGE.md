AI was used for multiple sections of this assignment. The Makefile and .vscode compile files were built entirely by chatgpt-6. The helper function inside of test_tally.c to capture printed outputs was also developed entirely by chatgpt-6.  Inline suggestions using Copilot were used for some of the function development, although I had to make some edits along the way when the AI was not able to deduce how the functions would interact with each other. A big thing Copilot struggled with was tally_print(). I put together a detailed description of the function inputs, outputs, and behavior, but it was unable to produce a sufficient alphabetical ordering. The code it put together did print in alphabetical order, but it would've skipped names in every array except for some special cases. I ended up writing this function by hand, using 2 nested for loops.
