This refactored folder added 4 new .c files (main.c, stats.c, histogram.c, test_stats.c), moving the entry point from readings.c to main.c, and modularizing the original code. Upon using "make test", the 4 tests under test_stats.c run as well as the given regress.sh file. In order to check outputs of individual files, run ./main < data/<filename>.txt (note the change from ./readings to ./main).

Main now serves as the entry point from the code, with almost none of the necessary operations exist inside of it anymore. It sets up the arrays (ticks, temps, hums), temperature threshold value, and entry argument checking. Otherwise, it moves data to and from functions and handles majority of printing operations. 

readings.c has 2 functions: readings_parse() and printer(). readings_parse() takes an input stream (stdin), the ticks, temps, and hums array, as well as two constants, line_length and max_readings. It returns the three arrays filled with all valid readings from the input stream up to max_readings as a structure titled readingStats. printer() is a helper function which prints number of valid readings, skipped readings, and whether any readings came in at all.

stats.c has three functions: stats_fill(), stats_max(), and stats_threshold(). stats_fill takes an input array and the reading count from readings_parse, passed through from main. It calls helper function stats_max(), which is a recursive function to find the maximum value from an array. stats_max() checks for stack overflow at 9999, just below the test case provided in the requirements document. In reality, the current setup will never reach that value with max_readings = 1000. stats_fill() returns a structure "stats" with the min, max, and mean of an input array. stats_threshold() finds the longest run of temperature values above a certain threshold (non-inclusive), defined within main. It returns the highest number of array values above the threshold in a row and the index of the starting tick for the run.

histogram.c has 1 function, histogram_print(). It takes 4 inputs: the temperature array, reading count from readings_parse() (passed through main), the number of bins and bin width, where the latter of the two are defined constants inside main. It prints out a histogram using asterisks, where tempartures are tallied into bins of bin width, with bin ranges labeled as well as the number of asterisks printed.
